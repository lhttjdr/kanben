# 刊本語法

刊本源文件（`.kb`）是纯文本，采用 LaTeX 风格。设计原则：

- **两层分开，按字符区分**：标记只用 ASCII 符号（`\ { } [ ] %`），正文只用书里本来就有的字（汉字、全角标点）。古籍正文里不会出现这些 ASCII 符号，所以两层永不混淆，不用猜，正文也几乎不需要转义。
- **去掉标记就是原文**：正文里的《》「」【】都只是标点，保留原义。书名号画成波浪线还是括号，由版式选项决定，不归语法管。
- **只有一种标记形式**：`\命令[參數]{內容}`。解析器只认这个形式；命令的含义由一张命令表决定，加新命令不用改解析器。
- **出错有位置**：每条错误都带行号、列号，编辑器里点一下就跳过去。漏写的闭合符号只影响自己那一层。

## 设定

写在行首，位置不限（习惯上放在开头）：

```latex
\book{資治通鑑}        % 書名，印在版心
\volume{周紀一}        % 卷名，印在版心
\studio{刊本}          % 堂號，印在版心下方
\setup[columns=9, cells=18]
```

`\setup` 可用的键：

| 键 | 取值 | 默认 |
|---|---|---|
| `columns` | 每半葉行數，1–40 | 10 |
| `cells` | 每行字數，4–60 | 20 |
| `format` | `scroll`（長卷，不分葉）、`leaves`（冊頁：分葉，带版心） | scroll |
| `punct` | `judou`（句讀，不佔格）、`grid`（佔格）、`bare`（白文，去標點） | judou |
| `punct-color` | `red` `blue` `green` `ochre` `ink` `gray` | red |
| `title-mark` | `wavy`（左側波綫，括號不顯示）、`bracket`（保留括號） | wavy |
| `font` | `mincho`（明朝）、`fangsong`（仿宋）、`system`（系統字體） | mincho |
| `engine` | 編輯器預覽用的排法：`classic`（原版排法，見下）、`svg`（刊本字格排版） | classic |
| `numbers` | 版框下标行號（算籌數碼）：`on`、`off` | on |
| `column-width` | 行寬，以字為單位，1–3 | 1.6 |
| `head` | 天頭高，以字為單位，0–10。不指定时，有眉批就自动加高到 3 | 1 |

## 块级

| 写法 | 含义 |
|---|---|
| `\heading{標題}` `\heading[2]{標題}` | 标题，1–6 级。一级顶格，其余低若干格。后面可以接行内内容（如夾注） |
| 段内换行 | 平擡：另起一行，与上行同高 |
| 空一行 | 分段 |
| 每多空一行 | 版面上多空一整行 |
| `\indent[2] 正文` | 低二格 |
| `\raise[1] 正文` | 擡頭：高出版框一格 |
| `\bottom[1] 正文` | 靠底排，离底一格（撰者、落款） |
| `\begin{indent}[2]` … `\end{indent}` | 环境：其中每段都低二格（与段首属性累加）。也可用 `raise` `bottom` |
| `\toc` `\toc[2]` | 目次：列出（二级以内的）标题，按级低格，葉碼靠底。葉碼自动算出 |
| `\toc` 后紧接若干行 | 手写的目次：每行一条（不再自动列标题） |
| `\byline 某　撰` | 撰者、校者署名（靠底，下留空） |
| `\outline 正文` `\detail 正文` `\remark 正文` | 綱目體的綱（大字）、目，按語 |
| `\pipa 譜字` | 琵琶譜（用琵琶譜字體） |
| `\list 甲`↵`乙` `\list[unordered] …` | 單兒：段中每行一條。默认有序（列），`unordered` 是无序（集） |
| `\colors[孔雀綠, 葛巾紫, 靛青] 正文` | 字色。给一种就整段同色；给几种就逐行轮换（交替行色），標點不变色 |
| `\begin{quote}` … `\end{quote}` | 引文（引詩）：其中各段整体低一格 |
| `\begin{list}[unordered]` … `\end{list}` | 分段單兒：其中每段一条 |
| `\begin{table}[標題, header=both]` … `\end{table}` | 表格：每行一列，格子之间用 `&` 分开。`header` 是 `row`（首列）、`column`（首行之外每行的首格）、`both`、`none`。紧接在段落后面（不空行）就属于那一段 |
| `% 注释` | 到行尾都不排 |

段落属性写在段首管整段；写在段内某一行的行首，只管那一行，并覆盖同类的段落属性。

## 行内

| 写法 | 含义 |
|---|---|
| `\note{…}` | 雙行夾注。排满一行就折到下一行，最后一段左右平分 |
| `\note[single]{…}` | 單行小注 |
| `\note[right]{…}` `\note[left]{…}` | 側行小注：小字只排在右（左）半边，佔正文字格 |
| `\note[pair]{右\\左}` | 並行：两行小字并排，左右各为一段（如标题下之注） |
| `\side{…}` `\side[left]{…}` | 單側行：正文字體的小字，只排在右（左）半边，佔正文字格。多用于副題、側書款，也可以是正文 |
| `\comment{…}` `\comment[stagger]{…}` | 句段旁注（旁批）：沿行的右侧排小字，不佔正文字格；`stagger` 字距拉开 |
| `\endnote{…}` `\endnote[所注之字]{…}` | 尾注（校勘記）：文中只标编号，注文列在段后，按段编号 |
| `\head{…}` | 眉批，排在天頭 |
| `\name{…}` | 專名號（左側直綫） |
| `《…》` `〈…〉` | 正文里的書名號 |
| `\title{…}` | 不带括號的書名（只画波綫） |
| `\emph{…}` | 圈點。参数：`circle`（◦，默认）`dot`（•）`sesame`（﹅）`comma`（﹆）`box`（ロ，琵琶譜） |
| `\stroke{…}` | 校勘標記。参数：`line`（抹，右側直綫，默认）`dot`（右側實點）`circle`（右側空圈）`tint`（改字色） |
| `\name[double]{…}` | 專名號的另一式（兩側有綫） |
| `\rhyme[ru, 1]{翟}` | 韻腳的四聲標記：`ping`●、`shang`■、`qu`◆、`ru`▲，数字是韻部（定颜色） |
| `\ruby[◓]{鳳}` | 字右的小标记，如平仄 ○●◒◓ |
| `\pitch[清黃]{呦}` `\pitch[黃, left]{呦}` | 樂譜旁字：字右（左）正書律呂等譜字 |
| `\inv{…}` | 陰文。形状：`square`（平頭，默认）`round`（圓頭）`hex`（六角）`flower`（花頭）`each`（逐字圆形）`lantern`（疊燈籠） |
| `\frame{…}` | 墨圍。形状同上；`\frame[each]{…}` 即带圈字 |
| `\frame[hex, narrow]{…}` | 窄式：框只包住字，不贴界行（正文的框默认贴界行） |
| `\span{…}` `\span[prev]{…}` `\span[2]{…}` | 兼行：这段字跨到后（前）一行（或几行），排在几行的正中，并佔去那几行的同样几格 |
| `\rod{1971}` `\rod{4720, -398}` | 算籌數碼：个位、百位用縱式，十位、千位用橫式，零作〇；负数带斜綫，几个数用逗号分开。复制得到 Unicode 算籌字符 |
| `\rod[suzhou]{589}` `\rod[gua]{167954}` | 蘇州碼子；數字卦（筮數） |
| `\digits{18:20}` | 縱中橫排的阿拉伯數字（可带小数点、冒号、负号），四位一断 |
| `\glyph{瓊}` | 字書的字樣（字图） |
| `\figure{\image{圖.png}}` `\figure{\map{名}}` | 插图。整段只有插图就占整行，否则居行上 |
| `\del{…}` `\ins{…}` | 校勘删、增 |
| `\color[blue]{…}` | 字色：`red` `blue` `green` `ochre` `ink` `gray` |
| `\compose{⿰木鬼}` | IDS 组字，支持嵌套，如 `⿱艹⿰氵去` |
| `朝〪` | 四聲圈發，写在字后：〪平（左下）〫上（左上）〬去（右上）〭入（右下） |
| `\\` `\\[2]` | 另起一行；另起一行并高出二格 |
| `　`（全角空格） | 空一格。编辑器里按 Tab 输入 |
| `\{ \} \[ \] \%` | 转义；`\《 \》 \〈 \〉` 表示不当書名號的字面括號 |

规则：

- 命令名是 ASCII 字母；参数写在 `[ ]` 里，用逗号分隔，可以是 `round` 或 `raise=2` 的形式。
- 命令可以嵌套：`\note{《史記》曰\name{微子}}`。
- 元素不能跨行。没闭合的元素在行尾自动闭合，并报错。
- 夾注、旁行、眉批、兼行里不能再套夾注、旁行、眉批、兼行（会提示，并按普通文字排）。
- 未知命令会报错，但其中的文字照常保留，不会丢字。

## 標點

- **句讀**（默认）：`，、。；：？！` 不佔格，小字附在前一字右下；前引號附在后一字右上，後引號附在前一字右下。括號、省略號仍佔格。
- **佔格**：每个標點佔一格，改用直排字形。行首禁則：`，。」` 之类排不下时挂在上一行末尾，不会出现在行首。
- **白文**：去掉句讀和引號。

从版面复制文字时，直排字形会还原成普通标点，组字复制出 IDS 串，隐藏的书名号括号也会带上。

## 字體

正文默认用明朝（源樣明體，与思源宋體同源），也可选仿宋（朱雀仿宋）；旁批、眉批用楷書（霞鶩文楷）。三种都是 SIL Open Font License 授权的开源字體，切成一字一个的网页字体后改名为 KB Fangsong、KB Mincho、KB Kai，随附授权文件；浏览器只下载页面上用到的字。字體缺字时依次退回明朝、系統字體。

## 原版排法

`\setup[engine=classic]`（或工具欄「排法：原版」）時，源碼先譯成原版排版器的標記，再由移植的原版排法排印，結果與原版逐像素相同。對應關係：
