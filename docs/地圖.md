# 电子地图

正文里写 `\figure{\map{南徼圖}}`，插图框里就嵌一张可以拖动、缩放、倾斜的地图。

用到三个文件，都放在 `地圖/` 目录下（网站上是 `web/地圖/`）：

| 文件 | 作用 |
|---|---|
| `南徼圖.json` | 地图内容：看哪里、叠什么 |
| `南徼圖.png` | 静态替补图：单独打开 SVG、导出图片、打印时显示这张 |
| `index.html`、`map.js` | 地图页（所有地图共用） |

地图页可以单独打开：`地圖/?圖=南徼圖`。

## 数据格式

```json
{
  "title": "南徼圖",
  "source": "示意：郡界、路綫皆約略",
  "base": "古",
  "bounds": [[104.8, 15.2], [110.6, 22.6]],
  "features": [
    { "type": "area",  "label": "交趾郡", "color": "#8e5a8a", "ring": [[105.2, 21.9], [106.2, 22.2], [107.2, 21.6]] },
    { "type": "arrow", "label": "馬援南下", "color": "#b03a2e", "width": 4, "curve": true,
      "path": [[109.15, 21.6], [107.8, 21.25], [106.3, 21.1]] },
    { "type": "place", "label": "龍編", "at": [106.07, 21.05], "symbol": "capital" }
  ]
}
```

坐标一律写 `[经度, 纬度]`。

### 视野

| 键 | 含义 | 默认 |
|---|---|---|
| `bounds` | `[[西, 南], [东, 北]]`：让这片地方正好填满框（推荐，框的长宽随版式而变） | — |
| `center`、`zoom` | 中心与缩放级（没有 `bounds` 时用） | 洛阳，5 |
| `pitch`、`bearing` | 倾斜角、方位角（度）；有倾斜时自动开地形起伏 | 0 |
| `base` | 底图：`古`（纸色、地形晕渲、水系，不画今日的路、界、地名）、`淺`、`街` | `古` |
| `terrain` | `false` 关掉地形 | 开 |
| `globe` | `false` 用平面投影 | 球面 |
| `source` | 写在版权说明前面的出处 | — |

### 覆盖物（`features`）

| `type` | 必填 | 可选 |
|---|---|---|
| `arrow` 箭头 | `path`：一串点，箭头在最后一点 | `label`、`color`、`width`（像素）、`dash`（虚线）、`curve`（经过各点画平滑曲线） |
| `line` 线 | `path` | 同上，无箭头 |
| `area` 区域 | `ring`：边界上的点（首尾不必重复） | `label`（竖排写在区中）、`color`、`opacity`（默认 0.25） |
| `place` 地点 | `at`、`label` | `symbol`：`city`（点，默认）、`capital`（空心圈）、`battle`（圈叉）；`color` |

### 旧图（`rasters`）

把一张扫描的旧地图对到经纬度上，叠在底图上：

```json
"rasters": [
  { "label": "舊圖", "url": "大清一統輿圖.jpg", "opacity": 0.7,
    "corners": [[西北角], [东北角], [东南角], [西南角]] }
]
```

地图左上角会出现滑杆，读者可以调旧图的透明度，和今天的地形对照。请用版权已过期的图。

### 现成的 GeoJSON（`geojson`）

`"geojson": ["東漢郡界.geojson"]`：历代界线等现成数据直接叠上。各要素的 `color`、`opacity`、`width` 属性决定样式。

### 历代政区：CHGIS

`tools/map/chgis.py` 从 CHGIS V5 摘出某一年、某一范围的郡（府州）界和县治，存成上面说的 GeoJSON：

```sh
uv run --with pyshp --with pyproj --with shapely python tools/map/chgis.py \
    CHGIS目录 42 104 15 116 26 web/地圖/南徼圖-CHGIS.geojson
```

- 参数依次是：数据目录、公元年份（公元前写负数）、西南东北范围、输出文件。
- 数据从 Harvard Dataverse 的 CHGIS V5 Shapefiles（doi:10.7910/DVN/M7WEFY，标为 CC0）下载，解压 `v5_time_pref_pgn_utf.zip`、`v5_time_cnty_pts_utf.zip` 到同一目录。原始数据不进仓库，只放摘出的那一小块。
- 郡界画成淡色区、虚线边，郡名写一处；县治是小圆点，放大到 6.5 级以上才写名。
- 在 `.json` 里写 `"geojson": [{ "url": "南徼圖-CHGIS.geojson", "color": "#8a6d1f" }]`。
- 出处要写进 `source`，改动记在 `地圖/NOTICE`。
- CHGIS 只到今天中国境内；越南等地（如交趾、九真、日南）没有数据，只能另画示意。早于 1350 年的郡界也有缺漏，用前先查。

## 静态替补图

改了 `.json` 之后，替补图要重新截一张：在浏览器里打开 `地圖/?圖=名&still`（不显示按钮），截下与插图框同样大小（版式一览里是 430×615）的画面，存成 `地圖/名.png`。

## 数据来源

底图、地形、水系来自 OpenFreeMap（OpenStreetMap 数据）、Natural Earth、Mapterhorn，历代政区来自 CHGIS V5，地图库用 MapLibre GL，出处都显示在地图右下角。
