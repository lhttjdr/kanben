    語法速查

    標記只用 ASCII 符號，正文只用書裏本來的字；去掉標記即原文。

    寫法效果
    \note{…} \note[single]{…}雙行夾注 / 單行小注
    \note[right]{…} \note[left]{…}側行小注（只排一邊，佔格）
    \note[pair]{右\\左}並行（兩行小字並排）
    \side{…} \side[left]{…}單側行（正文字體小字，佔半邊字格）
    \comment{…} \comment[stagger]{…}句段旁注（旁批）
    \endnote[字]{…}尾注、校勘記（列在段後）
    \head{…}眉批（天頭）
    \name{…}專名號
    《…》 〈…〉 \title{…}書名號（正文標點，畫法見「書名號」選項）
    \emph{…} [circle dot sesame comma box]圈點
    \stroke{…} [line dot circle tint]校勘標記：抹、點、圈、改色
    \rhyme[ru, 1]{翟} \ruby[◓]{鳳} \pitch[清黃]{呦}韻標（四聲、韻部）/ 字右小標 / 樂譜旁字
    \inv{…} \frame{…} [square round hex flower each lantern]陰文、墨圍：平頭、圓頭、六角、花頭、逐字圓圈、疊燈籠；加 narrow 為窄式
    \span{…} \span[prev]{…}兼行：跨到後（前）一行
    \rod{1971} \rod{-6} [suzhou gua]算籌數碼 / 蘇州碼子 / 數字卦
    \digits{18:20}縱中橫排的數字
    \glyph{瓊} \figure{\image{圖.png}}字樣 / 插圖
    \del{…} \ins{…}校勘刪、增
    \color[blue]{…} red blue green ochre ink gray字色
    \compose{⿰木鬼}IDS 組字
    \toc \toc[2]目次（自動葉碼）；後面緊接幾行則是手寫的目次
    \byline \outline \detail \remark \pipa寫在段首：撰者署名 / 綱 / 目 / 按語 / 琵琶譜
    \list \list[unordered]寫在段首：單兒，每行一條
    \colors[孔雀綠, 葛巾紫]寫在段首：字色，幾種就逐行輪換
    朝〪 〪〭〫〬四聲圈發（附前一字）
    換行 \\ \\[2]另起一行 / 另起並擡二格
    \heading{…} \heading[2]{…}標題
    \indent[2] \raise[1] \bottom[1]寫在行首：段首管整段，段內某行只管該行
    \begin{indent}[2] … \end{indent}環境：其中各段都低二格
    \begin{quote} \begin{list} \begin{table}[標題, header=both]引文 / 分段單兒 / 表格（每行一列，格子用 & 分開）
    空行 / 多空行分段 / 版面空行
    \{ \} \[ \] \% % 注釋 Tab 鍵轉義 / 注釋 / 全角空格
