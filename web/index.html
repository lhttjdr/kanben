    語法速查

    標記只用 ASCII 符號，正文只用書裏本來的字；去掉標記即原文。

    寫法效果
    \note{…} \note[single]{…}雙行夾注 / 單行小注
    \note[right]{…} \note[left]{…}側行小注（只排一邊，佔格）
    \side{…} \side[left]{…}旁行小字、句段旁注
    \comment{…}朱色旁批
    \head{…}眉批（天頭）
    \name{…}專名號
    《…》 〈…〉 \title{…}書名號（正文標點，畫法見「書名號」選項）
    \emph{…} [circle dot sesame comma]圈點
    \stroke{…}朱抹
    \inv{…} \frame{…} [square round hex flower each lantern]陰文、墨圍：平頭、圓頭、六角、花頭、逐字圓圈、疊燈籠；加 narrow 為窄式
    \span{…} \span[prev]{…}兼行：跨到後（前）一行
    \rod{1971}算籌數碼
    \del{…} \ins{…}校勘刪、增
    \color[blue]{…} red blue green ochre ink gray字色
    \compose{⿰木鬼}IDS 組字
    \toc \toc[2]目次（自動葉碼）
    朝〪 〪〭〫〬四聲圈發（附前一字）
    換行 \\ \\[2]另起一行 / 另起並擡二格
    \heading{…} \heading[2]{…}標題
    \indent[2] \raise[1] \bottom[1]寫在行首：段首管整段，段內某行只管該行
    \begin{indent}[2] … \end{indent}環境：其中各段都低二格
    空行 / 多空行分段 / 版面空行
    \{ \} \[ \] \% % 注釋 Tab 鍵轉義 / 注釋 / 全角空格

    設定：\book{書名} \volume{卷名} \studio{堂號} \setup[columns=9, cells=18, format=leaves|scroll, punct=judou|grid|bare, punct-color=red, title-mark=wavy|bracket, column-width=1.5, head=3]
